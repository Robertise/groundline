What this tool will not do

  1. It never sends a message that a person has not approved, word for word.
  2. It never messages the same person twice from the same account, including after a crash or a retry.
  3. It never retries a send whose result is uncertain. It asks you to check on X first.
  4. It sends no automatic follow-ups.
  5. It does not follow, like, repost or reply for you.
  6. It reads X only through the official API with your own account's access. No scraping, no browser automation, no purchased data.
  7. It does not look people up outside X.
  8. It cannot read replies: X does not return messages from encrypted conversations to apps. You mark replies by hand.
  9. It cannot reach people who closed their DMs, or who accept requests only from verified accounts when your account is not verified. It shows these as blocked, with the reason.
  10. It uses one sending account, a daily cap ({{ daily_cap }} per day) and a pause between messages.
  11. In dry-run mode it never sends.
